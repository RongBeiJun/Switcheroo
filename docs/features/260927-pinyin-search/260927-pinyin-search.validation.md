# 中文窗口名拼音搜索 用户验证

## 验证说明

- 验证对象：搜索框对**中文标题/进程名**窗口支持拼音全拼与拼音首字母搜索（如"微信"可用 `weixin` 或 `wx` 命中）。
- 环境/前置条件：Windows，运行 `Switcheroo\bin\Release\switcheroo.exe`（Release 编译产物）；准备至少一个**标题为中文**的窗口（如微信、中文网页、中文名的资源管理器文件夹）。
- 输入方式：搜索框输入拉丁字母（非中文）。若输入法为中文状态，请先切到英文/直接输入（当前 "修复输入法冲突" 已能处理回车，但拼音查询本身要求输入法不把字母转成汉字）。

## 待跟进

- 本轮修订一处**单元测试断言错误**：`Initials_WX_Matches` 原期望 `Score=1`，但 `"微信"` 的首字母恰为完整的 `wx`，属"首字母前缀"应为 `Score=3`（与 `"百度浏览器"`→`bdllq`→3 一致）；已改为 3 并补一条真正的"首字母包含"用例（`"腾讯微信"`→`txwx` 中段 `wx`→1）。当前全部 48 个单测通过。
- **NPinyin 许可证已解决**：原 `NPinyin 0.2.6321.26573` 无 LICENSE（=保留所有权利），已替换为 **`WuTong.NPinyin 1.0.0`（MIT）**——同名 `NPinyin` 命名空间、`net35` 程序集（`NPinyin.dll`），非中文/常用汉字转换结果与原库一致（`微信→wei xin`、`百度浏览器→bai du liu lan qi` 等）。仅 `Pinyin.GetPinyin(char)`（静态）改为 `Pinyin.ConvertToPinyin(string)`（实例），`PinyinMatcher` 内一处调用相应调整；48 个单测在替换后全部通过。
