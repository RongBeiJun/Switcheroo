## 待跟进

第一轮验证发现 3 个问题，已修复：

1. **缩略图黑色**：DWM thumbnail 的 `rcSource` 误用屏幕绝对坐标（窗口不在屏幕原点时区域全错 → 黑屏），改为不设置 rcSource（DWM 显示整个源窗口）+ rcDestination 直接用 `GetClientRect` 物理尺寸。已用独立 WinForms/WPF 程序实测 DWM thumbnail 可正常显示、非黑屏。
2. **缩略图太小**：320x200 → 自适应源窗口比例（最大 520 宽），无固定 letterbox。
3. **动态过滤标签点击无实际功能**：`TextChanged` 开头 `if (!tb.IsEnabled) return;`，AutoSwitch 模式（tb 禁用）下点击标签设置过滤后不刷新列表；且禁用态 tb.Text 是占位提示文字会被拼进查询。改为独立 `RefreshFilter()`（绕过 IsEnabled 检查、禁用态用空查询），点击标签直接调用。新增 2 个单测锁定过滤链路（`WindowFiltererProcessFilterTest`）。

第二轮验证反馈已修复：

4. **缩略图黑边**：预览窗口固定 480x300 + letterbox 保比例导致四周黑边。改为窗口尺寸跟随被预览窗口宽高比自适应（`FitWindowToSource`），`rcDestination` 铺满整个客户区，无黑边。
5. **高分辨率屏幕模糊**：主窗口 `AllowsTransparency="True"` 使 WPF 走分层窗口位图渲染路径，非 100% 缩放下被 OS 拉伸模糊。已移除透明度（普通无边框窗口视觉一致），并新增 `app.manifest` 声明 `PerMonitorV2` DPI 感知、csproj 登记；`MultiMonitorHelper` 改为按目标屏幕实际 DPI（`GetDpiForMonitor`）换算坐标。
